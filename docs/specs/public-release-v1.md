## 公开配置与运行边界

公开模板不填写任何实际模型、服务地址或密钥。使用者配置自己的 OpenAI 兼容服务参数；密钥只从 PIPAPER_API_KEY 注入内存。配置、凭据、依赖、权重、索引与会话目录忽略跟踪。拒绝配置中的密钥、任意请求头及 URL 凭据。错误、trace 和快照进行密钥脱敏。

Pi SDK 固定 1.0.4，包管理锁文件保留。只暴露 search_papers 和 retrieve_chunks；不加载个人 Pi 资源、MCP、默认文件或 shell 工具，不修改 F:/piagent 上游。不自动重试或预热。产品普通问答不依赖已耗尽的实验授权，使用独立、有限、持久化的本地会话预算：启动前保留轮次，每轮请求尝试不超过 12，search 不超过 2，retrieve 不超过 4；辅助、失败和压缩请求均计数。

提供 /help、/corpus、/scope、/trace、/memory、/compact、/budget 和 /quit，支持快照恢复；压缩请求在下一轮预算内执行。恢复绑定模型非密钥参数、源代码与索引身份。成本和服务端权重版本未知时明确记 unknown。

## 复现契约

reproduce/ 独立管理题集、原始输出的公开派生记录、人工/AI 判定、源哈希、评分器及指标登记表。不得将多个重叠视图相加，或统一套用 295 分母。

- Intent、Query 改写、边界、端到端、引用及主任务分别登记 100、100、55、70、242 和 295 等实际范围。
- 压缩与恢复单列 30 组 × 4 轮，记录欠费失败补跑的对应关系；主任务原始结果不被补跑覆盖。
- 离线复核读取保存的输出与既有语义判定，明确不是重新调用模型或重新作人工评审。新模型在线运行属于新身份，不能保证复刻服务端历史分数。
- 模型只读取 corpus。Gold、题集、评分与判定只在独立复核进程。
