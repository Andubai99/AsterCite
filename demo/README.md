# 三分钟展示

在根目录执行 npm run demo，展示一组真实四轮保存记录；演示明确标记 replay，API调用0。dialogue.json 的每轮绑定原输出哈希，包含答案实际引用的来源段落。

演示顺序：

1. 介绍固定48篇论文库，以及“回答必须有实际检索证据”的约束。
2. 展示第一轮问题与回答的引用段落，再看后续指代、论文切换或用户纠正。
3. 执行 npm run reproduce，看原47题检索提升和各指标明确的分母。
4. 配置自己的服务并启动 CLI 时，展示 /corpus、/scope、/trace、/memory、/budget；/compact 后提问，再退出并恢复同名会话。

演示口径：完整效果数据来自保存的冻结实验；通用公开模板的接入/边界验证与正式效果评测分别说明。可用的简历事实应从 docs/results.md 挑选，不把 Pipeline完成率当答案正确率，不写未获得的独立人工评审。

仓库当前提供 CLI，未开发 Web UI。离线回放只展示已有答案，不会查询私有文件或消耗模型额度。
